# 目录组织参考

本文档为目录组织参考示例，按需创建，不强制一致；
包结构应反映模块边界与依赖关系。

## 职责分层

- 按功能职责划分子目录，禁止所有文件平铺于同一层级。
- 目录树应反映模块边界与依赖关系。

## 顶层结构（参考）

```
com.{app}.{dev}/
├── data/                    # 全局共享数据层（MediaStore / OkHttp / DataStore 实现）
├── domain/                  # 全局领域层（歌词、播放列表、在线搜索接口）
├── di/                      # 依赖注入
├── navigation/              # 页面路由
├── log/                     # 日志系统
├── update/                  # 检查更新
├── floatingwindow/          # 全局悬浮窗
├── service/                 # 后台服务（唯一播放服务与前台通知）
├── dialog/                  # 全局弹窗
├── ui/                      # 全局共享 UI 组件（含加载 / 错误 / 空态）
├── utils/                   # 工具
├── screens/                 # 页面模块
├── theme/                   # 主题配置
├── {App}Activity.kt         # 单 Activity 入口
└── {App}Application.kt      # Application 入口
```

## 标准页面结构（信息型 / 卡片式页面示例）

```
screens/home/
├── data/                    # 页面数据层
├── domain/                  # 页面领域层
├── overlay/                 # 页面遮罩浮层
├── service/                 # 页面后台服务
├── dialog/                  # 页面弹窗浮层
├── utils/                   # 页面工具
├── component/               # 页面共享组件（两形态通用内容）
├── compact/                 # 紧凑布局（窗口宽度小：竖屏手机）
│   ├── CompactAssembly.kt   # 紧凑布局组装器
│   ├── title_area/
│   │   └── TitleArea.kt     # 顶部标题
│   ├── welcome_area/
│   │   └── WelcomeArea.kt   # 欢迎卡片
│   └── about_area/
│       └── AboutArea.kt     # 关于卡片
├── expanded/                # 展开布局（窗口宽度大：横屏 / 平板）
│   ├── ExpandedAssembly.kt  # 展开布局组装器（同名分区另一形态）
│   ├── title_area/
│   │   └── TitleArea.kt     # 顶部标题
│   ├── welcome_area/
│   │   └── WelcomeArea.kt   # 欢迎卡片
│   └── about_area/
│       └── AboutArea.kt     # 关于卡片
├── {ScreenName}Screen.kt    # 页面入口：按 WindowSizeClass 分发 compact / expanded
├── {ScreenName}UiState.kt   # 页面级 UI 状态（全局唯一）
└── {ScreenName}ViewModel.kt # 页面级 ViewModel（全局唯一）
```

要点：
- compact/ 与 expanded/ 只包含 View（渲染与交互分发），不含状态与逻辑；
- 两形态布局一致的内容放 component/，不进分区；
- 任务型页面（表单 / 设置等）无需拆形态，可不建 compact/ / expanded/。

## 列表页变体示例

```
screens/playlist/            # 歌单 / 歌曲列表页
├── data/                    # 列表数据（本地曲库 / 在线搜索）
├── domain/                  # 列表业务接口
├── component/               # 列表项与空态等共享组件
├── song_list_area/          # 两形态列表差异大时按分区组织
│   └── SongListArea.kt      # 列表分区
├── {ScreenName}Screen.kt
├── {ScreenName}UiState.kt
└── {ScreenName}ViewModel.kt
```

## 导航接入（参考）

- 单 Activity 入口，页面路由集中在 navigation/；
- 页面间跳转统一经导航，不依赖跨页 ViewModel；
- 全局共享 UI（对话框、悬浮窗等）放置于顶层，避免页面各自实现。
