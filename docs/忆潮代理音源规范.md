# 忆潮代理音源规范

> 版本: v1.0.1 | 整理日期: 2026-09-5

代理音源（Proxy Source）是一个 JSON 文件，描述第三方音乐接口的调用方式。导入后，应用在对应平台的搜索、音质选择、播放与缓存优先走该音源；音源不可用时自动回退内置解析。

## 数据流总览

```
搜索 (search) ──► 歌曲列表（含 id / sourceId / coverId）
                    ├─► 播放 / 缓存 ── url 动作 ──► 音频直链
                    ├─► 歌词         ── lyric 动作 ──► LRC 文本
                    └─► 封面         ── pic 动作 ──► 封面地址
```

## 快速开始

1. 按本文档编写 JSON 文件。
2. 在应用「设置 → 代理音源 → 导入音源」，选择本地 / 链接 / 文本导入。

## 顶层结构

```jsonc
{
  "name": "音源名称",            // 必填；同名重复导入时覆盖旧音源
  "version": "1.0.0",           // 可选
  "author": "作者",              // 可选
  "homepage": "https://...",    // 可选
  "description": "描述",        // 可选
  "platforms": {                 // 必填，至少覆盖一个平台
    "wy": { /* 平台定义 */ },
    "qq": { /* 平台定义 */ }
  }
}
```

### 平台键

| 键 | 平台 | 键 | 平台 |
| -- | ---- | -- | ---- |
| `wy` | 网易云 | `kg` | 酷狗 |
| `qq` | QQ 音乐 | `kw` | 酷我 |
| `mg` | 咪咕 |    |    |

其余键被忽略。

## 平台定义

每个平台可声明五类动作，均为可选；未声明的动作自动回退内置解析。

```jsonc
{
  "wy": {
    "search":    { /* 动作定义 */ },  // 按关键词搜索歌曲
    "url":       { /* 动作定义 */ },  // 按曲目与音质换取直链
    "lyric":     { /* 动作定义 */ },  // 获取 LRC 歌词
    "pic":       { /* 动作定义 */ },  // 封面 ID 换封面地址
    "playlist":  { /* 动作定义 */ }   // 按歌单 ID 拉取歌单歌曲
  }
}
```

## 动作定义（Action）

```jsonc
{
  "method": "GET",                    // 可选，GET / POST，默认 GET
  "url": "https://api.example.com",   // 必填，请求地址模板
  "params": { "name": "{keyword}" },  // 可选；GET 拼查询串，POST 作请求体
  "query": { },                       // 可选；POST 时追加到 URL 的查询参数
  "headers": { "User-Agent": "lx-music" }, // 可选，渲染后原样发送
  "qualities": { "standard": 128, "high": 320, "lossless": 999 }, // 仅 url 动作
  "result": { /* 结果映射 */ }
}
```

### 请求语义

- **GET**：`url` 与 `params` 拼出查询串，如 `https://api.example.com?name=晴天`。
- **POST**：`params` 以 `application/x-www-form-urlencoded` 作为请求体；`query` 追加到 URL 查询串。

### 占位符（Placeholder）

`url`、`params`、`query`、`headers` 中可用 `{name}` 占位符，运行时替换；缺少取值时按空字符串渲染（可借此做「缺省省略」）。

| 占位符 | 适用动作 | 含义 |
| -- | -- | -- |
| `{keyword}` | search | 搜索关键词 |
| `{page}` | search / playlist | 页码（搜索固定 1；歌单从 1 逐页递增） |
| `{count}` | search / playlist | 每页条数（搜索固定 50；歌单默认 50） |
| `{playlistId}` | playlist | 歌单 ID（由分享链接解析出） |
| `{id}` | url / lyric | 曲目数字 ID |
| `{sourceId}` | url / lyric | 平台自定义标识，缺省同 `{id}` |
| `{coverId}` | pic | 封面 ID |
| `{quality}` | url | 当前音质映射值（来自 `qualities`） |
| `{title}` / `{artist}` | 全部 | 歌名 / 歌手 |
| `{album}` / `{duration}` | 全部 | 专辑名 / 时长毫秒（占位保留） |

### 音质映射（`qualities`）

| 键 | 含义 | 示例 |
| -- | ---- | ---- |
| `standard` | 标准（128kbps） | `128` |
| `high` | 高品（320kbps） | `320` |
| `lossless` | 无损（FLAC/Hi-Res） | `999` |

- 可整体省略：三档音质均执行 `url` 动作，`{quality}` 渲染为空字符串，适合「固定返回同一直链」的接口。
- 只声明部分档位：未声明的档位不生效，回退内置解析。

## 结果映射（`result`）

字段值为 **JSONPath**（子集见下节），指向响应体中的取值；提取失败或类型不符时返回空，回退内置解析。

### search

| 字段 | 说明 |
| -- | -- |
| `list` | 结果数组路径；缺省时响应体本身为数组 |
| `id` | 曲目数字 ID；缺省回退 `sourceId` 的稳定哈希。同一音源内重复 ID 只保留一条 |
| `title` | 歌曲名 |
| `artist` | 歌手名；字符串数组自动以 ` / ` 拼接 |
| `sourceId` | 平台自定义标识（如 QQ songmid、酷狗 hash），url/lyric 使用 |
| `coverUrl` | 封面直链（与 `coverId` 二选一） |
| `coverId` | 封面 ID，经 `pic` 动作换真实地址；两者都缺省则无封面 |
| `duration` | 时长毫秒数（可选） |

### playlist

复用 search 的 `list`/`id`/`title`/`artist`/`coverUrl`/`coverId`/`sourceId`/`duration` 字段，另支持：

| 字段 | 说明 |
| -- | -- |
| `playlistName` | 歌单名称；解析失败回退默认名「导入歌单」 |
| `total` | 歌单歌曲总数；用于判断分页是否拉满 |

**分页语义**：从第 1 页逐页请求（`{page}` 递增），满足以下任一条件停止：

1. 某页歌曲数组为空；
2. `total` 配置且累计去重数量 ≥ total；
3. 某页返回数量不足一页（< `{count}` 对应值）；
4. 本页无新增条目。

歌单接口通常需 token 认证，按接口要求在 `params` / `headers` 中声明即可。

### url / pic

| 字段 | 说明 |
| -- | -- |
| `url` | 返回的直链；空字符串视为解析失败 |

**响应体即直链**：响应体可直接是纯文本 URL，此时 `result` 可整体省略（等效 `result.url: "$"`）；若为 JSON（如 `{"url": "https://..."}`），仍需用 `result.url` 指明路径。直链为 `http://` 或 `https://` 均可直接播放，并同时用于播放与缓存下载（按后缀推断格式存入系统下载目录）。

### lyric

| 字段 | 说明 |
| -- | -- |
| `lyric` | LRC 原歌词文本 |
| `tlyric` | 翻译歌词文本（可选，按时间戳合并） |

## JSONPath 子集

仅支持按 `.` 分段与 `[n]` 下标，`$` 前缀可省略。

| 表达式 | 含义 |
| -- | -- |
| `$` | 根节点（响应 JSON 本体） |
| `$.data.list` | 依次取对象字段 |
| `$.songs[0].name` | 取数组第 0 项后再取字段 |

## 运行机制

1. **生效范围**：仅作用于声明了动作的平台与动作类型。
2. **优先级**：代理优先 → 失败（网络异常 / 返回空 / 字段解析失败）→ 回退内置解析。
3. **多音源冲突**：同一平台被多音源覆盖时，各动作独立取最近导入且配置了该动作的音源——不同音源可分别覆盖搜索 / 播放 / 歌词 / 封面 / 歌单而不互相顶替。
4. **即时性**：导入、移除后立即影响后续搜索与播放，无需重启。
5. **频率控制**：应用不会额外限速，请按接口限额设计调用频率；搜索结果封面逐条换取（默认最多 8 张）。
6. **缓存来源**：缓存下载与播放同源，即音源解析出的直链。

## 完整示例

以网易云 `url` 动作为例：

```jsonc
{
  "method": "GET",
  "url": "https://music-api.gdstudio.xyz/api.php",
  "params": { "types": "url", "source": "netease", "id": "{id}", "br": "{quality}" },
  "qualities": { "standard": 128, "high": 320, "lossless": 999 },
  "result": { "url": "$.url" }
}
```

选择「高品」播放 `id=2652820720` 时，应用发出：

```
GET https://music-api.gdstudio.xyz/api.php?types=url&source=netease&id=2652820720&br=320
```

响应 `{ "url": "https://m801.music.126.net/.../xxx.mp3", ... }`，取 `$.url` 作为播放与缓存直链。

若接口直接返回音频直链（纯文本，非 JSON），连 `result` 都可省略：

```jsonc
{
  "name": "直链音源示例",
  "platforms": {
    "wy": {
      "url": {
        "url": "https://api.example.com/get?id={id}",
        "headers": { "User-Agent": "lx-music" }
      }
    }
  }
}
```

该音源只声明了 `url` 动作：搜索 / 歌词 / 封面自动回退内置解析；省略 `qualities` 时任意音质均执行该动作。

## 注意事项

- `qualities` 三键可只声明部分，未声明的档位回退内置。
- 聚合接口直链通常带时效签名，请勿长时间缓存，应用侧按需实时解析。
- 需认证的接口（如 `X-Token`）在 `headers` 中声明，并确保返回 `trusted` 结果，否则部分平台会拒绝服务。
- 按接口要求设置 `User-Agent`（如 `LX-Music-Mobile`），避免风控。
