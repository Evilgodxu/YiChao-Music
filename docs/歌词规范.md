# 歌词规范

> 版本: v1.0.0 | 整理日期: 2026-09-05

应用内歌词（内嵌歌词、本地导入、手动编辑、歌词缓存文件）统一采用**增强 LRC** 文本格式：在标准 LRC 行时间戳的基础上，增加逐字时间标签与翻译块。歌词按行解析，时间戳驱动的行为在播放时同步展示。

## 格式速览

```lrc
[00:00.000]序章
[00:03.500]第一句歌词[tr]第一句翻译[/tr]                              ← 单行歌词（可选翻译）
[00:06.250]<00:06.250>风<00:06.750>吹<00:07.250>过[tr]风吹过[/tr]      ← 逐字歌词
```

## 一、时间戳

时间戳位于方括号 `[ ]` 或尖括号 `< >` 内，格式为 `mm:ss.xxx`：

| 部分 | 说明 |
| -- | -- |
| `mm` / `ss` | 分钟 / 秒 |
| `xxx` | 毫秒（3 位）；小数 1~3 位均兼容：1 位按十分位（`.5`=0.5 秒）、2 位按百分位（`.50`=0.50 秒）、3 位按毫秒（`.500`=500 毫秒） |
| 前导零 | 位数不限，`[000:00.000]`、`[0:0.5]` 均合法且值等价 |
| 小时制 | 长音频支持 `hh:mm:ss.xxx`（如 `[01:02:03.000]` = 1 小时 2 分 3 秒），行时间戳与逐字时间戳均适用 |

## 二、单行歌词

```lrc
[mm:ss.xxx]正文[tr]译文[/tr]
```

- `[mm:ss.xxx]`：该行歌词的开始时间
- `[tr]` 与 `[/tr]` 之间为可选的翻译文本，展示在正文下方

示例：

```lrc
[00:00.000]序章
[00:03.500]第一句歌词[tr]第一句翻译[/tr]
[00:06.250]第二句歌词[tr]第二句翻译[/tr]
```

## 三、逐字歌词

```lrc
[mm:ss.xxx]<mm:ss.xxx>正文<mm:ss.xxx>正文[tr]译文[/tr]
```

- 行内每个 `<mm:ss.xxx>` 标记其后文字的开始时间，逐字高亮按此驱动
- 逐字模式下正文须全部写在 `<时间>` 标签内，首个标签之前的文字不会显示
- 标签内的文字持续到下一个 `<` 或行尾

示例：

```lrc
[00:00.000]<00:00.000>风<00:00.500>吹<00:01.000>过[tr]风儿吹过[/tr]
[00:02.000]<00:02.000>雨<00:02.500>落<00:03.000>下[tr]雨落下[/tr]
```

## 四、边界与约定

| 约定 | 说明 |
| -- | -- |
| 一行仅一个行时间戳 | 多个行时间戳不会拆分，多余时间戳作为正文内容显示 |
| 时间戳可重复、顺序不限 | 同一时间允许存在多行；解析后按时间自动排序 |
| 无时间戳的行被忽略 | `[ar:歌手]`、`[ti:标题]` 等元信息标签或纯文本行不会进入歌词 |
| 翻译块一行取一个 | 取首个 `[tr][/tr]` 作为译文，建议每行最多一个 |
| 编码 | UTF-8 |
| 缓存写入 | 应用写出的歌词缓存与本格式一致（时间戳输出毫秒 `mm:ss.xxx`，解析兼容 1~3 位小数） |
